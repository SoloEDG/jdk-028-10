# LOGIC LAB

## 安装与本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的地址。类型检查和构建：

```sh
npm run typecheck
npm run build
```

## 卡诺图实验台

顶部切换到「卡诺图实验台」。目标表最多 6 输入 / 3 输出，每个输出可含无关项（×）。

- **圈定**：在画布上按住拖动；行 / 列首尾环绕，5–6 变量使用分层网格（层内 4×4，层间同位置相邻）。
  松开后按“固定变量取值”生成乘积项；圈住的格子不是矩形时会拒绝并说明原因。
- **锁定**：选中圈组后点「锁定」。求解时锁定项作为硬约束，**不会暗中解锁**；
  如果合法锁定项让全局最优变差，右侧同时保留“未锁定参考”和“含锁定项”两个成本。
- **补齐覆盖**：点「补齐覆盖 / 求全局最优」。求解器以**共享网络的真实门成本**为目标
  （一条乘积项只建一次与门，扇出到多个输出的或树），不是逐输出分别最少圈数；
  右侧还列出逐输出独立最少圈数作为对照。
- **检查覆盖**：显示每个输出尚未覆盖的必须为 1 的格子、圈组误含的必须为 0 的格子、门成本与当前表达式。
- **多个最优**：求解后列出多个同等最优方案，点击浏览；「把当前方案放到画布」才会替换学生圈组（保留原锁定状态）。
- **变量顺序**：左右调整顺序只换行列 / 层的摆放；圈组保存的是输入组合，切换后仍覆盖原格子。
- **生成电路**：表达式先逐格核对目标表，再用真实 `evaluate()` 仿真全部输入核对；
  共享项生成一根项线扇出到多个输出的或树。任一不一致都会拒绝生成。生成后切回工作台即可看到接好的网络，
  并在卡诺图页底部保留逐格对照。
